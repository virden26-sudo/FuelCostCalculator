# Fuel calculator GitHub demonstration

An independent CSC262 demonstration, prepared by Codex. This is newly written example code, not a copy of the submitted homework.

Run with JDK 17 or newer:

```sh
java FuelCostCalculator.java
```

`main` contains the initial calculator. `validate-input` adds input validation.
The local Git history records both stages. GitHub demonstration: remote repository hosting, a validation issue, and a pull request from `validate-input` to `main`. The pull request remains open for review.
